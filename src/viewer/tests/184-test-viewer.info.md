# 184-test-viewer.lua

Issue 301's referees for its third step, the reference viewer (183).
On a home of five mailboxes whose inbox is written as each gatherer
writes it, after which the disk home is moved away (so the viewer can
only be reading RAM): the joined tree, with children by label whose
tags run the other way (broken: `own-order`) and a flagged member shown;
a room found by its path of labels or the start of its tag, showing the
corrected text, the deletion, the signature and the edited mark; `write`
putting a typed file in 301's shape into the room's own gatherer, at
this clock, and refusing a signature 214's rule would not read back; a
gatherer polling `typed/` never reading half a file the viewer writes
(broken: `in-place`); and each gatherer's problem lines.  End to end,
two real gatherers on 127.0.0.2 and .3: written in A's viewer, filed and
sent by A, read in B's viewer from A's address, in A's as `from: me`,
and no longer waiting in A's tree.  Run under the loopback-only wrapper:
`luajit src/viewer/tests/184-test-viewer.lua [project]`; prints PASS/FAIL
and "counts <passed> <failed>".
