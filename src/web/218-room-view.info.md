# 218-room-view.js

What the page shows, worked out apart from drawing it (issue 405): the
room trees joined from every mailbox's `.tree` as the reference viewer
(183) joins them, and the open room as plain lines (side, name where the
speaker changes, anchor `m-<id>`, time, marks, text) with the home's
notices after the last message.  The page's script places them; the
stand-in prints them as text (`tree`, `room`).
