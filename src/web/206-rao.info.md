# 206-rao.js

The one object the page's scripts share, `rao`, and its byte helpers
(`rao.bytes`: UTF-8 text to and from byte strings, arrays, hex, random
bytes, SHA-256, and the words shown when a browser gives the page no
WebCrypto).  Bytes cross the page's parts as one character per byte, as
Lua holds them (402 decision 3).  `rao.broken` names a referee's broken
version; in a browser it is always "".
