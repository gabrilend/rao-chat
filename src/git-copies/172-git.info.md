# 172-git.lua

Running git for a mailbox's repository (issue 215).  `find` (the
program, or the words naming it as missing), `check_name` (a home name
safe as a ref), `identity`, `run`/`must`, `ensure` (the repository with
the `rooms` branch checked out and `labels` excluded), `ref`,
`commit_tree` and `commit_folder` (a folder committed to a branch with an
index of its own, nothing checked out).  Every command runs without the
machine's or the person's git settings, with hooks off and no password
prompt.
